# HRSMS — Hotel Reservation Security Monitoring System

[이스트캠프] 가디언즈 정보보호 및 인프라 관리 10기 2차 팀 프로젝트
**2지(Easy)하조**

호텔 예약 시스템 보안 관제 솔루션

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | Hotel Reservation Security Monitoring System (HRSMS) |
| 진행 기간 | 2026.06.01 ~ 2026.06.19 |
| 팀 구성 | 2팀 \| 2지(Easy)하조 \| 김혜미(팀장) 외 4명 |
| 핵심 기술 | GNS3, Ubuntu, pfSense, Suricata, rsyslog, Graylog, GoAccess, PMM |

**선정 배경**
- 민감 정보(예약자·투숙객 개인정보)를 대량으로 취급하는 서비스의 높은 데이터 보안성 요구
- 다양한 서비스 모듈 기반의 보안 시나리오 테스트에 최적화된 대상
- 24시간 운영 서비스의 비즈니스 연속성 및 실시간 관제 필요성

**프로젝트 목표**
- 호텔 예약 서비스 인프라 전반을 보호하고 가시성을 확보하는 통합 보안 관제 시스템(HRSMS) 구축
- 다층 보안 솔루션(Firewall, VPN, IDS/IPS) 도입을 통한 실전형 방어 체계 마련
- Shell Script 기반 보안 업무 및 로그 분석 프로세스 자동화

## 팀 구성 (WBS)

| 이름 | 역할 | 담당 업무 |
|---|---|---|
| 김혜미 | 프로젝트 매니저(PM) / 팀장 (PMM, 모의해킹) | 취약점 설정, 모의해킹, PMM 구축, 전체 일정 및 보고서 작성, 발표 |

## 기술 스택

| 구분 | 기술/도구 | 버전 | 용도 |
|---|---|---|---|
| OS | Ubuntu | 24.04 LTS | 보안 관제 서버 및 웹 서버 구동 OS |
| 네트워크 보안 | pfSense / Suricata | pfSense 2.7.2 / Suricata 7.0 | 경계 보안(방화벽) 및 침입 탐지/차단(IDS/IPS) |
| 로그 수집 | rsyslog | 8.2112.0 | 네트워크 및 시스템 보안 로그 중앙화 전송 |
| 데이터 분석 | Graylog | 6.1.16 | 통합 로그 검색, 인덱싱 및 위협 알림(Alerting) |
| 웹 가시화 | GoAccess | 1.5.5 | 웹 서비스 접속 로그 실시간 시각화 및 공격 패턴 분석 |
| 시스템 모니터링 | PMM(Percona Monitoring and Management) | 3.8.0 | 서버 자원(CPU, RAM, 디스크) 및 DB 성능 실시간 모니터링 |

## 시스템 아키텍처

- **External Network**: 인터넷, 공격자(Kali), 고객/원격 사용자
- **DMZ Zone(대외 서비스망)**: Victim 웹 서버
- **Internal Subzone(내부 업무망)**: 업무용 PC(VPCS)
- **SOC/Mgmt Zone(보안 관제망)**: rsyslog / Graylog / GoAccess 서버
- pfSense(Firewall/VPN)를 경계로 각 구역을 분리하고, 원격 사용자는 VPN 터널을 통해 내부망에 접근

## 수행 결과 요약

### 프로젝트 수행 범위

| 영역 | 내용 |
|---|---|
| 네트워크 인프라 구축 | GNS3를 활용한 가상 기업 네트워크 토폴로지 설계 및 구축 |
| 서비스 환경 구축 | 웹 서버 및 DB를 활용한 호텔 예약 서비스 플랫폼(Eazyhotel) 구축 |
| 보안 솔루션 적용 | 방화벽, VPN, IDS/IPS 정책 수립 및 공격/피해(Attacker/Victim) 시나리오 기반 테스트 |
| 관제 및 자동화 | rsyslog·Graylog·GoAccess를 이용한 로그 통합 분석 환경 및 실시간 대시보드, 자동화 쉘 스크립트 개발 |

### 보안 관제 센터(SOC) 운영
- **탐지**(pfSense/Suricata): 위협 발생 시 즉시 차단 및 로그 생성
- **수집**(rsyslog): 차단/서버 로그의 중앙 서버 자동 전송
- **분석**(Graylog/PMM): 보안 위협 패턴 분석 및 DB 쿼리 병목·성능 실시간 정밀 분석
- **가시화**(GoAccess/PMM): 웹 트래픽 흐름 및 시스템 리소스 대시보드 실시간 시각화
- **운영 자동화**: Shell Script 기반 로그 순환(Logrotate) 및 관리 업무 자동화

### 모의해킹(펜테스트) 결과 요약

대상: Eazyhotel 호텔 예약 웹 서비스 (2026.06.05 ~ 2026.06.11 수행)

| No | 대상 | 취약점 | 위험도 |
|---|---|---|---|
| 1 | 로그인 페이지 | SQL 인젝션(인증 우회) | 상 |
| 2 | 로그인 페이지 | Open Redirection | 중 |
| 3 | 로그인 페이지 | 세션 고정(Session Fixation) | 상 |
| 4 | 회원가입 페이지 | Stored XSS | 상 |
| 5 | 예약 상세 페이지 | IDOR(부적절한 인가) | 상 |
| 6 | 메인 페이지 | SSRF | 상 |

총 6건의 주요 취약점을 식별했으며, 각 항목에 대해 매개변수화된 질의(Prepared Statement), 세션 재생성, HTML 엔티티 인코딩, 소유자 기반 인가 검증, URL 스킴/도메인 화이트리스트 적용 등 시큐어 코딩 조치를 완료하고 재검증까지 수행했습니다. 상세 내용은 [모의해킹 결과보고서](<./3_2지(easy)하조_모의해킹결과보고서.pdf>)를 참고하세요.

### 시스템 취약점 점검 결과 요약

KISA 「주요정보통신기반시설 기술적 취약점 분석·평가 방법 상세가이드」 기준, Eazyhotel VM 서버 대상 점검 수행

- 총 점검 항목 67개 중 취약 9건 발견 → 전 항목 조치 완료(최종 양호 67 / 취약 0)
- 주요 조치: root 원격 접속 제한, 패스워드 복잡성 정책, 계정 잠금 임계값, su 명령 제한, 불필요 계정 제거, 세션 자동 종료, FTP root 접속 제한, 로그인 경고 메시지, 시스템 로깅 정책 활성화
- `security_check.sh`를 cron에 등록해 매일 13시(체크인/아웃이 적은 시간대) 자동 점검하고 결과를 `/var/log/security_report_[날짜].log`로 기록하는 상시 모니터링 체계 구축

## 마무리

**기대 효과**
- **기술적 역량 강화**: 네트워크 설계부터 보안 솔루션 배치, 로그 분석까지 SOC 운영 전 과정 경험

- **보안 위협 대응 속도 향상**: 실시간 로그 시각화 및 자동화 스크립트를 통한 탐지·분석 시간 단축
